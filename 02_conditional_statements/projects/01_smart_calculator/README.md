# 🧮 Smart Calculator

A simple command-line calculator built using Python. It allows users to perform basic arithmetic operations, including addition, subtraction, multiplication, division, modulus, and exponentiation.

This project is part of my Python learning journey, created to practice conditional statements, user input, string handling, and basic input validation.

## ✨ Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)
- Exponentiation (`^`)
- Integer and decimal number support
- Input validation for numbers and operations
- Division-by-zero and modulus-by-zero protection
- Simple and organized terminal interface

## 🛠️ Technologies Used

- **Language:** Python
- **Interface:** Command-Line Interface (CLI)
- **Concepts:** Conditional Statements, User Input, String Handling, Basic Validation

## 🚀 How to Run

### Prerequisites

Make sure Python is installed on your computer.

### Steps

1. Clone the repository:

```bash
git clone https://github.com/harshit-k-dev/python-learning.git
```

2. Navigate to the project directory:

```bash
cd python-learning/02_conditional_statements/projects/01_smart_calculator
```

3. Run the program:

```bash
python main.py
```

4. Select an operation and enter two numbers when prompted.

## 💻 Available Operations

| Symbol | Operation | Example |
|---|---|---|
| `+` | Addition | 10 + 5 = 15 |
| `-` | Subtraction | 10 - 5 = 5 |
| `*` | Multiplication | 10 * 5 = 50 |
| `/` | Division | 10 / 5 = 2 |
| `%` | Modulus | 10 % 3 = 1 |
| `^` | Exponentiation | 2 ^ 3 = 8 |

## ⚠️ Error Handling

The calculator handles the following situations:

- Invalid operation selection.
- Invalid numerical input.
- Division by zero.
- Modulus by zero.

## ❓ FAQ

#### 1. What operations does the Smart Calculator support?

It supports six operations: addition, subtraction, multiplication, division, modulus, and exponentiation.

#### 2. Does the calculator support decimal numbers?

Yes. You can enter integer and decimal numbers.

#### 3. What happens if I try to divide by zero?

The calculator displays an error message because division by zero is not allowed.

#### 4. Can I perform multiple calculations in one execution?

No. The current version performs one calculation per execution.

#### 5. What happens if I enter an invalid operation?

The program displays an error message and terminates.

#### 6. Which programming language is used?

The project is developed using Python.

#### 7. Is this project suitable for beginners?

Yes. It is designed to practice conditional statements, user input, and basic validation.
