# Conditional Statements in Python

This folder contains my Python practice exercises on conditional statements, completed while learning Python through CodeWithHarry's *100 Days of Code / Zero to Job Ready Python* course.

## Topics Covered

- `if` statements
- `if-else` statements
- `if-elif-else` statements
- Nested `if-else` statements
- Comparison and logical operators
- Conditional expressions and decision-making
- User input and basic validation

## Exercise Structure

The exercises are divided into four levels based on complexity.

| Level   | Exercises | Concepts                             |
| ------- | --------: | ------------------------------------ |
| Level 1 |       1–5 | Basic `if` statements                |
| Level 2 |      6–10 | `if-else` statements                 |
| Level 3 |     11–16 | `if-elif-else` statements            |
| Level 4 |     17–24 | Nested conditions and combined logic |

## How to Run

Make sure Python is installed on your system.

Run the exercise file using:

```bash
python conditional_statements_exercises.py
```

Each exercise is written separately. Run the file and provide the requested inputs when prompted.

## Learning Objective

The objective of these exercises is to understand how Python makes decisions based on conditions and how to implement logical problem-solving using conditional statements.
